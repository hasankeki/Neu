# NurWallpaper

Android-Live-Wallpaper-App mit einer offline nutzbaren Bibliothek religiöser Inhalte.

## Inhaltsbereiche
- Koranverse
- Hadithe
- Du'a und Dhikr
- Esmaül Hüsna

## Grundprinzipien
- Offline-first, ohne Benutzerkonto und ohne Werbung
- Favoriten kostenlos
- Inhaltswechsel nach einstellbarem Intervall
- Dynamischer Kontrastschutz
- Quellen- und Rechteprüfung vor Veröffentlichung

## Projektstatus
Dieses Repository wird als Arbeitsrepository für NurWallpaper vorbereitet. Die fachlichen Kataloge und das Pflichtenheft werden vor dem Import einzeln geprüft. Ein erfolgreicher Android-Build oder Gerätetest ist derzeit noch nicht belegt.
